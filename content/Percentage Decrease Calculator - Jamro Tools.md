## **What Is Percentage Decrease?**

Percentage decrease shows how much a value has decreased compared with its original value.

For example, if a price decreases from **$100 to $80**, the decrease is **$20**. Compared with the original price of $100, this represents a **20% decrease**.

Percentage decrease is commonly used to measure:

* Price reductions  
* Sales decreases  
* Revenue decreases  
* Salary reductions  
* Population decreases  
* Website traffic decreases  
* Production decreases  
* Inventory reductions

---

## **Percentage Decrease Formula**

The percentage decrease formula is:

**Percentage Decrease \= ((Original Value − New Value) ÷ Original Value) × 100**

### **Formula Breakdown**

Original Value − New Value \= Amount of Decrease

Amount of Decrease ÷ Original Value \= Decimal Change

Decimal Change × 100 \= Percentage Decrease

For example, to calculate the percentage decrease from **200 to 150**:

200 − 150 \= 50

50 ÷ 200 \= 0.25

0.25 × 100 \= 25%

Therefore, the percentage decrease is **25%**.

## **Percentage Decrease Between Two Numbers**

To calculate the percentage decrease between two numbers, you need:

* The **original value**  
* The **new value**

The new value must be lower than the original value for the result to represent a percentage decrease.

Use the following formula:

**((Original Value − New Value) ÷ Original Value) × 100**

For example, calculate the percentage decrease from **400 to 300**:

((400 − 300\) ÷ 400\) × 100

(100 ÷ 400\) × 100

\= 25%

Therefore, the value decreased by **25%**.

## **Percentage Reduction From an Original Value**

Percentage reduction measures how much a value has been reduced compared with its original value. The calculation uses the same formula as percentage decrease.

For example, if a price is reduced from **$500 to $350**:

500 − 350 \= 150

150 ÷ 500 × 100 \= 30%

The price has been reduced by **30%** from its original value.

## **Common Mistakes When Calculating Percentage Decrease**

### **Using the New Value as the Base**

Percentage decrease should always be calculated using the **original value** as the base.

For example, when calculating the decrease from 100 to 75:

Correct:

(100 − 75\) ÷ 100 × 100 \= 25%

The original value of **100** is used as the denominator.

---

### **Confusing Percentage Decrease With Percentage Difference**

Percentage decrease measures how much a value falls from an original value.

Percentage difference compares two values when neither value is necessarily the starting point.

If you want to compare two values rather than measure a reduction, use the Percentage Difference Calculator.

---

### **Forgetting to Multiply by 100**

After dividing the decrease by the original value, multiply the result by 100\.

For example:

0.25 × 100 \= 25%
