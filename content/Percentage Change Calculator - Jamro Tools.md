## **What Is Percentage Change?**

Percentage change measures how much a value has changed from an original value to a new value.

It can show either an increase or a decrease:

* A **positive percentage change** means the value increased.  
* A **negative percentage change** means the value decreased.  
* A **0% change** means the value stayed the same.

For example, if a price changes from **$80 to $100**, the percentage change is:

(100 − 80\) ÷ 80 × 100 \= 25%

The price increased by **25%**.

Percentage change is commonly used to compare:

* Prices  
* Sales  
* Revenue  
* Expenses  
* Test scores  
* Measurements  
* Website traffic  
* Population  
* Investment values  
* Business performance

## **Percentage Change Formula**

The standard percentage change formula is:

**Percentage Change \= (New Value − Original Value) ÷ Original Value × 100**

### **Simplified Formula**

You can also write the formula as:

Percentage Change \=

(New Value − Original Value)

\---------------------------- × 100

Original Value

The **original value** is used as the reference value because percentage change measures how much the new value has changed relative to where it started.

### **Example**

To calculate the percentage change from **50 to 70**:

70 − 50 \= 20

20 ÷ 50 × 100 \= 40%

Therefore, the percentage change is **40%**.

## **How to Calculate Percentage Change**

To calculate percentage change between two numbers:

1. Identify the original value.  
2. Identify the new value.  
3. Subtract the original value from the new value.  
4. Divide the difference by the original value.  
5. Multiply by 100\.  
6. Interpret the result as an increase or decrease.

### **Example**

Find the percentage change from **200 to 250**.

#### **Find the difference**

250 − 200 \= 50

#### **Divide by the original value**

50 ÷ 200 \= 0.25

#### **Convert to a percentage**

0.25 × 100 \= 25%

**The percentage change from 200 to 250 is 25%.**

## **Percentage Change Between Two Numbers**

To calculate the percentage change between two numbers, you need to identify which number is the **original value** and which is the **new value**.

For example, suppose a value changes from **120 to 150**.

150 − 120 \= 30

30 ÷ 120 × 100 \= 25%

Therefore, the percentage change is **25%**.

The order of the values matters. Changing the original value changes the reference point used in the calculation.

For example, changing from **120 to 150** produces a **25% increase**, while changing from **150 to 120** produces a **20% decrease**.

## **Percentage Change vs Percentage Difference**

Percentage change and percentage difference are often confused, but they answer different questions.

### **Percentage Change**

Percentage change compares a new value with an original value.

**Formula:**

(New Value − Original Value)

\---------------------------- × 100

Original Value

### **Percentage Difference**

Percentage difference compares two values using their average as the reference.

**Formula:**

|Value 1 − Value 2|

\------------------- × 100

Average of Values

For example, if a value changes from **100 to 120**:

**Percentage change:**

20 ÷ 100 × 100 \= 20%

**Percentage difference:**

20 ÷ 110 × 100 \= 18.18%

The results are different because the calculations use different reference values.

## **Percentage Change vs Percentage Error**

Percentage change measures the change from an original value to a new value.

Percentage error is commonly used to compare an experimental or measured value with an accepted or reference value.

A commonly used percentage error formula is:

**Percentage Error \= |Experimental Value − Accepted Value| ÷ |Accepted Value| × 100**

For example, if an experimental value is **95** and the accepted value is **100**:

|95 − 100| \= 5

5 ÷ 100 × 100 \= 5%

The percentage error is **5%**.

The two calculations use different contexts and reference values, so percentage change and percentage error should not be treated as interchangeable.

## **Common Mistakes When Calculating Percentage Change**

### **Using the New Value as the Denominator**

The standard percentage change formula uses the **original value** as the denominator.

The correct formula is:

(New Value − Original Value)

\---------------------------- × 100

Original Value

---

### **Confusing Percentage Change With Percentage Difference**

Percentage change requires an original value and a new value.

Percentage difference compares two values relative to their average.

If there is no designated starting value, percentage difference may be the more appropriate calculation.

---

### **Reversing the Original and New Values**

The order of the values matters.

For example:

100 → 120 \= 20% increase

120 → 100 \= 16.67% decrease

Although the absolute difference is the same, the percentage change is different because the original values are different.

---

### **Forgetting the Negative Sign**

A negative percentage change indicates that the new value is lower than the original value.

For example:

(80 − 100\) ÷ 100 × 100 \= \-20%

This means the value decreased by **20%**.

---

### **Rounding Too Early**

Avoid rounding intermediate calculations unnecessarily. Keep the full value during the calculation and round the final percentage to the desired number of decimal places.
